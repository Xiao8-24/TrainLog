TrainLog 0.6.1 · 有氧与 Apple Watch 原生训练预览版

修正 Watch 启动页运动类型和泳池长度选择控件被压缩、文字裁切的问题，改用原生导航与列表选择，并标注当前选中项。开始按钮采用系统绿色。增加真实 watchOS 运动选择页截图，未模拟传感器数据。

最低 iOS 27 / watchOS 27，使用 Xcode 27。

力量动作库扩展到 128 个，支持器械、肌群、收藏和中英文检索；升级只补充缺失动作，保留原 ID、收藏与历史快照。

新增 38 种有氧与其他运动，包括跑走骑、游泳、器械有氧、间歇、徒步、球类、舞蹈、滑雪和瑜伽等。支持时长与适用距离、平均配速/速度、运动趋势与任意日期日历；不虚构力量组数或肌群刺激。手机计时运动支持实时活动与灵动岛。

新增原生 watchOS companion App：主动开始、暂停/继续、结束保存，显示系统采集的心率、活动能量和适用距离。先保存 Apple 健康，再通过受保护的离线文件传回 iPhone；收据防止重复导入和复活已删除记录。手机显示心率采样图、平均/最高心率与系统能量估算，不重复导出同一手表训练。

可单独授权读取 Apple 健康已有血氧与有氧适能（VO₂ max），显示日期、来源和前次变化。血氧为静止测量参考，不是运动中连续采集；VO₂ max 不从单次训练推算，也不保证每次产生新值。无传感器数据时不补零或套用通用热量公式。

SwiftData V1→V2 兼容升级保留数据库原位置。JSON 新导出版本 2，继续读取版本 1；CSV 增加运动与身体数据摘要列。手表心率/能量随训练进入备份，血氧/VO₂ max 参考仅用于查看。数据不发送到 TrainLog 服务器。

发布要求核心、数据库/健康队列、手机 UI 测试，以及含 Widget 与 Watch 的 Release 归档通过。模拟器不能验证真实传感器、健康/健身展示、手表后台与离线连接，需签名配对真机验收。

源码 ZIP 包含 iPhone、Widget 和 Watch 工程。IPA 未签名，不能直接安装；须分别签名三个产品，主 App 与 Watch 启用 HealthKit，主 App 与 Widget 配置相同 App Group。不是 TestFlight 或 App Store 发布。详见 Documentation/CARDIO_AND_WATCH.md。
