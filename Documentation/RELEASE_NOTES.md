TrainLog 0.7.0 · 同一场训练、快捷操作与原生体验预览版

连续输入合并保存，关闭或退后台时提交最新草稿；完成、放弃后取消旧写入。显示真实保存状态，失败可重试，非法输入不会覆盖有效记录。

草稿与已完成历史分开刷新，减少整个档案排序与小组件重建；历史配置建立索引，降低训练输入时的重复扫描。修复模板复用被较新空配置挡住的问题。

实时活动只在显示内容变化时更新，保留精确计时起点；训练组使用短系统转场。Watch 测量视图独立刷新，数字平滑转场并尊重减少动态效果，选择页面使用统一原生值类型导航。

新增已批准的同一场手机/手表力量训练：明确连接当前手机草稿，手表采集并保存健康记录，结果按请求标识附加到原逐组训练，不另建第二条手机记录；显示独立的真实采集区间。开始、暂停与结束仍由手表操作。

新增已批准的交互小组件与原生快捷指令：继续草稿、打开日历、按模板开始及结束当前休息。回到 App 校验状态，过期链接不会创建替代记录或结束另一场训练的休息。首次使用前需打开 App 同步共享摘要；操作需本机身份验证。

128 个力量动作、38 种运动类型及健康连接保留。新增关联元数据采用 V3 轻量迁移；JSON 导出版本3，继续导入1/2。云同步、每周计划和提醒未获批准，不包含在本版。

最低 iOS 27 / watchOS 27，Xcode 27。发布需核心、数据库/服务及手机 UI 测试与含 Widget、Watch 的设备归档通过。测试和原生截图不能替代配对真机的传感器、后台、导航和 Instruments 性能验收。血氧读取已有静止测量，VO₂ max 使用系统已有估算，不从单次训练推算。
