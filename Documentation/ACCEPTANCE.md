# iPhone 手工验收

以下场景**尚未执行**。应在 iOS 18 和计划使用的较新正式 iOS 版本各验收一次；至少覆盖一台小尺寸和一台大尺寸 iPhone。所有测试训练都应在独立测试档案完成。

| 场景 | 操作 | 预期 |
|---|---|---|
| A 人体高亮 | 快速记录点击胸部，切换前后、点击标签取消再选中，保存后查看概览，再删除 | 胸部独立选中；其他区域不被误选；列表同步；删除后重算 |
| B 详细映射 | 卧推完成 3 个正式组，查看肌群加权指标 | 胸 3，三头 1.5，前肩 1.5；图、详情、条形图一致 |
| C e1RM | 卧推 60 kg×8，RPE 8，完成正式组 | 显示估算 76 kg，实际重量纪录为 60 kg；缺少 RPE/RIR 不估算 |
| D 历史修改 | 把该组改成 70 kg×8，再删除最高纪录 | 容量、力量曲线和 PR 同步更新；删除后回到次佳纪录 |
| E 快速腿部 | 选择股四头/臀/腘绳肌，强度高，不填组数 | 产生覆盖与训练天数；不产生组数、容量或 e1RM |
| F 时间 | 记录今天、8 天前和 35 天前；切换今日/7/30/90/全部 | 日期范围变化与颜色、数值、历史一致 |
| G 空数据 | 初始空档案遍历四 Tab、图表、月历、年度图 | 无假训练、无虚构增长、无崩溃 |
| H 持久化 | 记录完整训练；另存草稿、设置、体重；关闭重开 | 完成训练和草稿分别恢复；草稿不进入统计；设置保留 |
| I 外观 | 浅色/深色、横屏、最大辅助字号、Reduce Motion、VoiceOver | 标签可读、内容可滚动、动作有替代入口、肌群可独立访问 |
| J 边界 | 同日多会话、跨年、kg/lb、每只哑铃、自重、辅助、计时、热身、递减、失败 0 次 | 遵守 README 的统计口径；无虚构容量；同日肌群天数去重 |
| K 备份 | JSON 导出/导入同一份两次、改用替换；导入重复 ID/无效数值/不兼容版本 | 合并幂等；替换确认；错误导入不改动本地；恢复副本可读 |
| L 计时 | 开始、暂停、后台、重启、手动修正，测试各休息时长 | 训练和休息计时符合墙钟截止时间；暂停不累积；无授权也能记录 |
| M 动作快照 | 自定义动作完成训练后改名/改肌群/改重量口径 | 历史分类不改变；不同负重口径不合并比较 |
| N 模板 | 新建模板、重排动作、填预设、启动、复制组、复用历史 | 动作顺序正确；模板/复制组均为未完成；替换配置需要确认 |
| O 错误 | 输入负重量、无效字符、不完整完成组；取消编辑；测试存储失败 | 明确提示；无效值不冒充保存成功；取消不改历史；原数据库不被重置 |
| P 导出 | CSV 中输入中文、逗号、引号、换行和公式前缀备注 | 保持列数与文本；数值使用 kg；缺失值为空；公式不会执行 |
